# 操作手册

使用初始化用户名（默认admin）和自己设置的密码登录管理页。HTTP会传输密码与会话，务必可信LAN使用。

- 连接概览：connected只表示WSS已连接，discovered只表示上游工具发现成功，不表示业务权限已通过。
- 配置：WSS/Key不回显，留空保留；清除Key需显式选择。保存只持久化，不自动重连。多人更新版本冲突时先重载。
- 工具：仅代码允许集合可选；采用、拒绝、采集有真实副作用，服务账号不代表说话人个人身份，操作前必须确认。超时未知不得重试。
- 测试：仅MCP初始化与工具列表，不发送真实tools/call。
- 应用：关闭旧连接再连接，观察connecting/error/connected；应用请求被接受不表示连接成功。
- 退出使当前会话失效。密码丢失不能随意删除hash重新初始化，应停服务并按明确授权轮换。

## v3设备与服务目录

JSON导入可直接点击“确认导入”：系统先自动校验并生成脱敏预览，再要求确认后一次保存；无需先手动点预览。导入不会自动授权设备。删除有实际工具授权的设备须两次确认，第二次列出设备名称和绑定服务，后端也检查confirm_bound。删除设备不删除共享MCP服务。同名设备在服务卡片中显示短ID，空工具授权不显示为有效绑定；不同ID不会按名称合并。

导航分开为设备管理、MCP服务目录、系统说明。设备列表点名称进入单台详情，不再编辑全局default设备的重复表单。新增设备默认停用、零服务绑定；保存授权后需明确应用。停用立即停止目标连接，删除需确认，不影响其他设备。

服务目录允许外部Streamable HTTP/SSE，不限Higress。市场服务需要提供实际MCP URL、传输及认证（none/Bearer/API Key）；不支持stdio命令、软件包执行或OAuth自动登录。公网HTTPS，私网目标必须明确确认风险，危险地址及所有重定向拒绝。API Key Header不可使用Host/Cookie等保留头。

新增服务后点击发现工具，仅初始化/列工具；随后去设备详情勾选所需服务工具。新增发现工具不自动授权，服务参数Schema改变需要重新复核授权。不同服务同名工具通过稳定前缀隔离；原六工具兼容别名保留。更改URL/凭据/传输会清发现快照，须重新发现并明确应用受影响设备。

通用MCP只向语音端返回文本，超过1024 UTF8字节或非文本明确报不支持；错误不变成成功。connected仅表示WSS连接，不证明业务API Key范围或实际操作权限。没有第二个不同小智WSS时，不能称真实双设备已验证。
