# 安装部署

在agent-mcp-proxy运行。Python3.11+，Docker Compose v2；


1. 使用现有Python环境或安装requirements.txt。
2. 运行`python doc/bootstrap_admin.py或python3 doc/bootstrap_admin.py`交互初始化管理员；不覆盖已有哈希，不在命令行传密码。
3. 准备忽略的secrets目录与config.example.json声明的文件；WSS和Key不进Git或镜像。权限：目录0700，秘密文件0600，所有者匹配非root容器UID。
4. .env配置BRIDGE_UID、BRIDGE_GID、BRIDGE_ADMIN_BIND_IP、BRIDGE_ADMIN_PORT（默认18082）、LINMO_DOCKER_NETWORK。
5. 创建runtime目录0700；`docker compose -f docker-compose.yml config --quiet`、`docker compose -f docker-compose.yml build`、`docker compose -f docker-compose.yml up -d`。

管理地址示例http://192.168.1.100:18082。HTTP不加密，仅可信LAN，外网不应映射；防火墙变更需单独授权。无Docker Socket，root只读、runtime可写、secret只读。

当前v3设备/服务目录已部署，管理员哈希/秘密保留。首次启动v3会先创建runtime/config.v2-backup.json（0600），再原子迁移旧配置；不得将旧镜像直接指向v3配置。回滚先停新服务，再恢复v2备份和before-catalog镜像，不能双连同一WSS。

服务可使用公网HTTPS或明确确认的私网HTTP/HTTPS，支持Streamable HTTP/SSE及none/Bearer/API Key；元数据地址、link-local、回环、跨源发送、重定向被拒绝，实际TCP连接使用已校验解析IP。市场OAuth/stdio不在本版支持范围。

部署不等于业务URL授权成功；不得仅凭容器Up或工具发现判断WSS/业务操作权限正常。实际外部服务测试需要获授权URL和凭据，不能用随机市场服务代替用户目标。
