# 升级与回滚

升级前备份当前镜像标签、docker-compose.yml、.env、runtime及secrets到受保护忽略目录；不要打印配置正文。当前目录迁移回滚镜像标签linmo/mcp-proxy:pre-migration已创建。

先构建新镜像，再停止旧代理并启动新代理，禁止同时连接相同小智WSS。仅操作代理服务，不down全栈，不down -v，不删除业务数据卷。

目录迁移时原运行目录完整副本已保存于仓库.superpowers/migration-backups中的时间戳目录，含私密数据，不能提交或分享。需要回滚时先停新代理，再从备份恢复原目录及compose挂载，以pre-migration镜像启动，不能在新代理还运行时启动旧WSS。

迁移验收页面/静态资源200、匿名API401、挂载新根、private config权限0600；用户原密码登录及第二台LAN电脑访问需要实际人工确认。后续v2升级须保留v1私有配置，降级不能让旧程序直接读取v2。
